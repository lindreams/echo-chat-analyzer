### 语言画像原话初版（2026-10-27，源码验收中，未发布）

展示词可点击查看当前分析范围内的真实原话，默认三条，全部列表每次十条；
按同一词法 token 匹配，区分出现次数与消息数，邻近上下文最多前后各两条／十分钟，过滤缺口与不确定会话身份／时间不猜连续性。
原话随离线 HTML / JSON 保存，分享报告也会分享文字；现有报告包说明已更新，无额外原文缓存。
语言画像保持原纵向模块与字体，只缩小间距；表达文化仅末尾成员区宽屏双列。
表情包仅缩小“使用风格”右侧数值，不改特色算法与章节布局。

验收发现微信原话残留群消息的 `sender_id:\n` 存储头部；昵称映射正常。来源适配已在确认群聊、非本人且头部与发送者完全匹配时去除头部，保留用户正文；明文与压缩内容均有回归，私聊、未知会话、本人文字与不匹配头部保持原貌。
重复文本检测去掉原有的 12 字重复单元上限，整条消息由同一句精确重复至少三遍时按既有质量规则排除；两遍强调与带额外正文的消息不套用这条规则。
表达文化不再显示没有可展示表达的成员空卡片，统计总量保持原口径；若全部成员都没有展示项，章节沿用不可用隐藏逻辑。
当前 schema `echo-report.v0.12`，分析修订 `echo-analysis.v12`；旧报告需重新生成。
日常 Core / UI Report 非慢测回归通过，另有实际离线浏览器、QQ / 微信导入到原话关联及来源审查定向验证。
微信来源定向测试中原生 WCDB 计数项因本轮未指定 CLI 路径而跳过，不扩大为原生读取全通过。
十万条全部命中的虚构压力样本会生成约 25 MiB 的 HTML，分页不能降低文件体积；超大群与旧机器仍需人工验收。

QQ 群已有受限明确引用关系，QQ 私聊未验证目标映射，微信官方库路径未读取引用承载类型；未新增通用回复分析。

## 卸载后本地数据清理待办（2026-10-25）

**现状，尚未实现清空选项：** 当前 Setup 卸载保留用户数据。软件内删除整份报告只删除

微信环境配置会将已保存的数据库密钥写入本地 JSON；删除报告或卸载程序不会移除该配置。
临时报告和 QQ 明文快照应由正常生命周期清理；目录存在不代表仍有聊天内容，异常退出或

收尾中改变卸载合同。验收时应明确当前仍保留数据，不将卸载成功等同于全部本地数据删除。

## Shutdown 与安装安全边界

普通退出可以在有界清理后离开；退出完成、窗口消失或退出码为 0，均不单独构成安装授权。
更新须经用户确认、空闲及安装身份检查、关闭任务入口、该次 shutdown 证据和包复验，
才调用官方 Velopack 交接并重启。软件内卸载同样要求可信清理与当前安装核验；
升级／卸载不得删除用户报告与配置，也不得管理用户自己的 QQ／微信进程。

[ShutdownResult](../src/qq_chat_analyzer/application/shutdown_models.py) 的安装准入要求以下五项
各出现恰好一次且全部为 SUCCESS：Direct DB 清理、保留的临时报告清理、QQ runtime 终止与凭据退役、
来源生命周期、GUI workers 静止。缺项、重复项、未知项、FAILED、TIMED_OUT 或 UNKNOWN 均拒绝；
普通汇总 status 为 SUCCESS 并不单独证明证据完整，历史缓存或调用方伪造结果不能替代本次关闭。

未使用的生产来源可通过已知无资源路径证明空闲；已使用来源缺少完整停止／drain 证明时保持 UNKNOWN。
微信 helper 进程树退出、Python reader／PIPE／句柄释放与 Node CleanupHook 完成是不同证据：
前两项成功不证明最后一项。UNKNOWN 是证据不足时正确的安全结果，不应为了让更新可用而改成 SUCCESS。
