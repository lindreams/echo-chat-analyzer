## 下一阶段：v0.2.0

**产品主题：综合小修；优先研究面向普通用户的 Windows Setup 和软件内一键更新。**

- 安装器与更新统一设计：目标是首次下载安装后，以后能在 Echo 内发现新版本、下载、校验、应用并重启；普通用户不再依赖手动解压 ZIP。
- 优先做小型技术验证，评估 PyInstaller `onedir`、安装器 / 更新框架、GitHub Release 分发、版本渠道以及老用户从 Portable 迁移。**技术验证通过不等于完成发布级升级闭环；不保证一定在 0.2.0 交付。**
- 安装程序目录必须与 `%LOCALAPPDATA%/LocalChatAnalyzer` 等现有用户数据、报告和个人配置隔离；更新失败需恢复可用状态，不得误删私有数据。
- 保留 QQ 跨机器兼容性问题的独立跟踪；根据首批反馈完成已有 GUI、报告、算法的小修，不把大型新功能塞入这一版。
- 长期版本主题与 1.0.0 的新功能目标详见 [ROADMAP.md](ROADMAP.md)。AI 能力继续留待 2.0 讨论。
