# 0.3.0 报告功能阶段交接

核对日期：2026-10-28。本次保存已实现源码及其验证，供继续开发与人工审核；
不是 0.3.0 正式发行。软件版本仍为 0.2.5，报告 schema 为 `echo-report.v0.16`，
分析语义版本为 `echo-analysis.v15`。现存发布阻塞见 [HARDENING](HARDENING.md)。

## 已实现并保留的成果

- 私聊互动：微信拍一拍、QQ 戳一戳接入来源校验、独立统计与“轻轻叫你一声”展示。
  展示双方次数及最近三次动作；身份无法确认时不推断，不改变普通消息、轮次、词频或表情统计。
  来源、身份与安全边界见 [DATA_SEMANTICS](../DATA_SEMANTICS.md)，
  取证与接入历史见 [语言原文与回复关系审查](LANGUAGE_ORIGINALS_AND_REPLY_AUDIT.md)。
- 聊天轮次：收紧总览、开场与接话图形、高光卡片；群聊“谁来起拍”采用已选圆环方案，
  保留成员完整发起次数、未确认归属及默认显示的可查找名单，长名单内部滚动。群聊桌面为左侧开场、右上小时分布、
  右下“热闹聚在哪里”，窄屏依次排列。集中度复用完整逐轮消息数，展示消息最多的约一成
  轮次贡献的消息份额，并注明实际轮数；少于两轮或记录不完整则隐藏集中度。
  右下同时纵向补充“话最多”和“聊最久”，同轮合并，移除群聊独立高光大框及消息密度、参与人数最多卡片。
  该排版已通过负责人预览确认并接入正式 HTML 导出；轮次划分阈值保持，私聊高光保持。
- 表情章节：减少节间留白，次要发现可并排，接力图保留整行；没有删减已选算法结果。
- QQ 素材队列：桥接查询与获取各自使用有界令牌桶，减少固定时间窗口造成的长时间等待，
  保留认证、运行代际、身份复核、串行下载、取消与资源释放约束。
- 无损报告存储：表情原件统一放入报告 `media/`，HTML 与 JSON 共用摘要命名文件；
  品牌图使用无损 WebP。原始素材不转码、不删帧，非 QQ 素材预算保持。
  分享须保留完整目录，旧报告不迁移；实际缩小比例取决于原报告的存储方式和素材分布。
- 语言画像：增加常用词可点击查看原话的轻量指引。

## 当前不能作出的结论

### 大群成员身份与参与人数

对已生成的大群报告核查发现：部分普通消息没有可确认的发送者身份。
这些消息仍参与全局消息统计和聊天轮次划分；成员统计只计算能够可靠归属的消息。
因此全群总量与成员合计可能不同；已有 `participant_count` 仅是已辨认成员数，
存在未知发送者时不能当作该轮真实参与人数。不能把“有部分成员被识别的轮次”当作身份完整样本。

现有群成员名称补全依据已有 UIN，不能据此证明已恢复所有缺失的 UID／UIN 映射。
历史报告不足以确认源字段缺失、非标准身份还是映射缺口；原临时载荷已清理，
本阶段没有重新取数来推断根因，也没有改变身份解析或轮次算法。

后续应在正常、受控的来源获取中核验匿名字段覆盖及可靠 UID／UIN 对应，
再决定是否修复现有适配。若采用“每轮参与人数分布”，应先增加或明确每轮未知发送者覆盖信息，
不能隐藏未知消息、合并成一个虚构成员、按昵称猜身份，或把已辨认人数包装成准确值。

### 未完成的产品设计

- 聊天轮次及右下补充记录的排版预览已确认；仍需使用新生成的真实报告复核最终效果。
- 群聊回复／互动关系独立成模块，不能以私聊拍戳已接入替代完成。
  显式 @、引用回复与群聊拍戳须分别核对来源、身份和方向，再确定统计及展示；
  不根据相邻消息推断关系强弱。当前没有实现该群聊模块。
- 完整聊天复现留待后续版本讨论，不在本阶段扩展。
- 更新分发可达性仍是 0.3.0 发布阻塞，尚未选定或迁移新源。

## 验证与交付边界

验证使用隔离用户目录和虚构样本，包括普通消息与动作分流、身份拒绝、范围过滤、
快照／素材所有权、序列化、素材原字节、打包引用和离线浏览器交互。
Git 收尾发现的内嵌图片旧断言已按共用外置原件合同调整，继续逐字节检查；
仅日志使用的身份诊断码维持不进入 GUI 展示名单。

本次 Fast 基线及受影响的离线浏览器、构建资源声明等 slow integration 检查通过。
符号链接用例因 Windows 权限跳过；原生 WCDB 计数集成未配置专用 CLI，未执行。
HTTP 请求边界用例初跑曾遇连接重置，单独及完整回归复跑通过；本次未修改该请求拒绝边界，
不能把复跑通过解释为已定位或消除偶发连接重置。

此前受控真人动作只证明本机来源结构与方向；本阶段仍需修改后从 GUI 重新生成真实私聊和大群报告，
核对统计、动画、长名单及最终排版。尚未完成本轮 Frozen／Setup、安装升级、卸载及跨机器验收，
源码测试或构建资源声明检查不能代替这些验收。本次不构建、上传或发布安装包。

建议下一步核验轮次新排版，并明确大群身份缺口及独立群聊互动方案；
发行前解决更新分发并按 [DEVELOPMENT](../DEVELOPMENT.md) 完成发行验收。
