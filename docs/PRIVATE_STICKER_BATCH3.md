## 结构化结果及关联边界

入口：`result.reports.private_stickers.stories`，版本 `private-sticker-stories.v1`。
算法版本仍为 `private-stickers.v1.1-batch2`。

- `candidates`：全部故事关联组，包含未入选的普通发现。
- `featured_ids`：确定性选出的至多三个故事 ID；没有算法配额。
- `moments`：接力事件的本地消息引用；`experiment_eligible` 标识是否满足密集斗图或同图互接实验条件。
  所有接力仍保留，普通四轮接力不会被改称为高光。

每个故事的 `findings` 是原七项结果的字段名和下标，不复制或删除算法候选。
`timeline` 按日期排序，保留采用、重逢、趋势窗口及接力的事件锚点；
招牌和共同习惯作为历史背景引用，不假装发生在同一天。
`sender_ids`、`identity_keys`、`media_keys`、`event_ids` 供后续关联和图片回退使用。
ID、消息 ordinal 和引用仅在本次分析内有效，不能作为跨导入永久身份。

关联采用简单、保守的规则：同一可靠素材、成员有交集、事件锚点重叠或相距至多七日，
合并后的锚点总跨度至多 90 日，且中间没有已知过滤缺口。
采用锚点是后用方首次观察日；重逢锚点是回归日，而非从上一次使用至回归的整个空白期。
趋势保留当前窗口。这些门槛是编辑关联规则，不是传播因果或统计显著性证明。

跨全历史的招牌／共同习惯只附到一个关联组，不充当合并两个年代事件的桥梁。
共同习惯优先使用原有 adoption 直接关联；其他情况附到末次已知使用附近的同素材组。
上下文引用仍指向完整原始证据；没有将其历史范围改写成事件时间。
接力重叠窗口关联到一个事件，保留全部窗口下标，以最强的一个有界窗口复现，
不把几十分钟的重叠窗口并成伪造的十分钟核心。相关素材故事只挂接一次该事件，
不会再产生一张重复的主要接力卡片；多素材接力也不会合并所有无关素材历史。

精选优先级使用可审查的趣味层级和具体反差：长间隔重逢、明显占比变化、
较长的作者交替互动、长期招牌、等量种类反差等；理由和原始指标保留在结构中。
普通 Top 3 招牌、最低门槛的共同习惯可为零级而不入选。
没有关系默契百分数、情绪解读或最终文案。当前层级仍需真实体验调整，
不同类型指标只作编辑优先顺序，不宣称客观地衡量了趣味。
媒体状态完全不参与事实、关联或本轮排序；候选和媒体引用为下一批可用图优先及缺图回退保留。

## 可检查的虚构结果

### 六项合成一段素材故事，风格独立保留

复用 `combined_scene()`：“打卡海豹”本人 1 月开始使用，对方在第 70 天首次使用；
本人间隔 49 日重逢，末期走红，双方在四个以上日期形成共同习惯，
第 70 天还有八轮互接。原候选仍为七类各一个。

本批实际产生两个故事、两个入选项：

1. 素材故事时间锚点 `[2025-02-14, 2025-03-16)`，引用
   `adoptions[0]`、`reunions[0]`、`trends[0]`、`signatures[0]`、
   `shared_habits[0]`、`relays[0]`；接力与经典瞬间共同引用事件 `interaction:105:113`。
   时间线中的趋势窗口、回归日、后用方首日和接力日期均能追溯，
   不把 70 日先后关系写成“本人教会了对方”。
2. 等量风格故事：抽取发送量 10 次，预期种类约 9.670 对 1，D2 约 52.632 对 1。
   这是跨素材的使用风格反差，独立于海豹的单图事件。

### 跨年和普通结果

新样本同一张 `old` 在 2025-04-11 和 2027-03-12 分别重逢，间隔证据为 96 日、696 日。
得到两个独立故事；全历史招牌最多作为其中一个的背景，不把两次重逢合并。
样本中其他素材也可有自己的真实重逢，不靠删除这些候选使断言通过。

复用第一批虚构场景，故事组／入选数为：日常 5／2、斗图 15／3、
不等量 3／1、短聊天 1／1、老朋友 3／3、丰富且相似 0／0、新潮流 2／1。
因此普通重复证据不会自动变成七栏。另一个新样本先有五场四轮接力，后有一场十二轮接力，
全部六场保留，最后发生的十二轮排在精选第一位，不被早出现的普通结果挤掉。
目前不同日期但内容相似的多场斗图仍可能占满三个名额；跨事件题材多样性是后续真实体验调整项，
本批不通过按算法固定配额掩盖这个问题。

## 经典瞬间本地实验

复用 `short_relay()`：两天 14 条消息，八个交替作者轮次，双方各四张图。
表情核心 `[2,10)`，上下文 `[0,11)`：开头两条文字、八条贴图、收尾文字均是原对象引用，
次日三条文字因超过 30 分钟不纳入。核心相差 140 秒，带上下文相差 160 秒。
另一新样本验证前后各扩一整个作者轮次，止于再下一轮，不吞掉后面的闲聊。

本地实验条件：五分钟内至少八次发送、双方各至少两次、原接力已有至少四个交替轮次，
且核心贴图消息密度至少一半；或同一可靠素材双方各至少两次、该素材自身至少四轮作者交替。
后者不会把 A、A、B、B 误当四轮互接。没有另建排序索引或高光模型。

上下文遇未知作者／时间、并列倒序或过滤缺口即停，明确记录停止原因。
最多扩展每侧 60 条上下文，拒绝超长的额外轮次并标记限制，核心不裁断。
消息对象保留全部内容段、关系和撤回信息；不按消息 ID 回捞或重排。
来源在导入前已省略的类型无法重建，预览始终说明这是导入过滤后的切片，不能宣称完整原聊天。

预览入口为 `presentation/sticker_moment_preview.py:create_local_moment_preview(moment, result.stickers)`。
在已有本机分析结果和 QApplication 的 GUI 线程中，用户明确要求预览时可调用：

```python
from qq_chat_analyzer.presentation.sticker_moment_preview import create_local_moment_preview

features = result.reports.private_stickers
moments = [m for m in features.stories.moments if m.experiment_eligible]
# 先在本地选择具体片段；不自动批量展示或导出。
if moments:
    preview = create_local_moment_preview(moments[0], result.stickers)
    preview.exec()
```

该函数仅构建内存 Qt 对话框，默认不显示、不写文件、不记正文日志，
无分享、媒体恢复、文件路径读取或网络请求；关闭时销毁播放器及缓冲。
只消费现有已验证 bytes／只读快照，不取得快照所有权。
已有可信预览明确标注并非原图；快照失效、缺图、解码失败或动画帧不符均显示占位，
不偷偷换成静态图或重新访问来源。未支持内容保留其顺序和占位，
回复关系不补造目标原文；正文用纯文本控件显示，不解释为 HTML。

  此批完成结构提取和消费已验证媒体的播放通路，不等于真实素材端到端验收。
