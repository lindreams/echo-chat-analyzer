## 3. 本轮验证与证据边界

- 复用现有虚拟环境，核验解释器、目标工作树源码导入、runtime／dev／gui／build 依赖及 pip check。
  没有安装升级依赖或改变共享环境；自动化及子进程用户目录均隔离，临时目录采用无链接短路径。
- 已复现历史残留的构建测试失败：模拟项目未准备 spec 前置要求的 SQLite 校验脚本、pins 和 DLL，
  导致测试在原版本拒绝、Frozen 路径断言之前失败。
- 复用现有虚构 SQLite PE／归档样本和真实校验逻辑补齐输入，保留原断言及生产安全检查。
  相关版本、Frozen 资源和 Windows runtime 合同回归通过。
- 群聊招牌展示先由既有浏览器场景复现缺失，再整合实现；私聊及各群聊容量档的浏览器回归通过，
  同时检查招牌事实、离线图片、缺图、成员切换和版式边界。
- 完整 Full 已在本轮隔离环境中执行完成，无失败；不再仅依赖此前环境校正后的定向复跑。
  跳过范围为未构建的 Frozen／Portable 产物、Windows 符号链接权限、缺少指定 NapCat 审计归档及配套 Node、
  原生 WCDB CLI；这些跳过不计为相应能力通过，仍保留后续验证门槛。
- 本轮不重跑真实 QQ／微信，不构建、安装或运行最终 Frozen／Setup。

历史 QQ 私聊原件／可信预览及微信群聊发送识别、普通 CDN 和 Facade 离线报告已有有限样本记录。
它们不覆盖本轮全部新增行为。当前版式、次级发现、QQ 取图、长记录性能和跨机器仍需真人验收。
历史 GUI 卡死和个别电脑连接故障没有本轮关闭证据，也不能据此断言当前一定复现。

   经负责人确认后实现、接入统一链路并验证，不直接套用私聊七项，也不临时引入新来源。

5. 人工审核后按明确授权集成，准备 0.3 版本和发布说明，重建最终 Frozen／Setup，
   完成启动退出、安装、升级重启、卸载、数据保留和目标机器验收后，再申请正式发布。

整个表情功能尚未达到最终发行候选或可直接上线状态。
