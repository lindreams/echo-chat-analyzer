## 七项候选与资格复核

正式路径：Rich 正式过滤结果 → `StickerData`／`aggregate_stickers` → 单份
`StickerFactIndex` → `analyze_private_stickers` → `select_sticker_stories` →
`build_sticker_memories` → 同一素材目标集合的媒体恢复 → V2 HTML／JSON。
来源／会话混合、可靠双方不成立等情况保持不可用，不猜测身份。

| 算法 | 当前候选资格与稀疏样本影响 |
| --- | --- |
| 采用先后 | 双方同一可靠素材的首次可辨认使用不在同日，时间与输入顺序相容；后用方至少 3 次／2 日。相关未知发送、时间或过滤缺口可能阻断先后判断。只描述观察顺序。 |
| 旧爱重逢 | 此前至少 3 次／2 日，间隔至少 `max(28, 3×此前使用日间隔中位数)`；其间本人其他可靠图至少 3 次／2 日，或消息至少 20 条／3 日；未知与过滤缺口不能遮挡沉寂。短聊天自然不满足。 |
| 使用变化 | 观察跨度至少 14 日，14～59 日取相邻 7 日窗，60 日起取相邻 30 日窗，每周及末端扫描；走红要求前窗可靠发送至少 3 次、后窗本图至少 5 次／2 日、数量至少三倍（前窗为零时按 1 作基数）、占比至少翻倍（原为零时后窗至少 10%）；淡出要求此前本图至少 5 次／2 日、降至三分之一以内、占比至少减半，后窗可靠发送至少 5 次／2 日。本图时间未知、窗内过滤缺口和遮挡低使用窗的相关未知事实会阻止输出。完整候选保留每个合格扫描。 |
| 招牌 | 复用原有习惯资格：至少 4 次、4 日、4 周、28 日跨度、已辨认发送占比至少 10%。特色独立故事另要求跨度至少 180 日或排名在 Top 3 之外，避免重复基础榜；普通招牌仍可作关联背景。基础统计规则不变。 |
| 接力 | 完整 Rich 作者轮次中至少四个交替表情轮，轮间严格正向且不超过 120 秒，首末不超过 600 秒；不跨纯文字对方轮、未知作者／时间、同秒／倒序或过滤屏障；保留极大窗口，未知素材仍能证明发送。缺少原位置溯源时不输出接力。 |
| 共同口头禅 | 双方各至少 3 次、2 个使用日、各自完整可靠素材发送占比至少 10%；保留首末日期、未知时间标记和对应采用证据。本轮移除故事层另设的双方至少 5 次／3 日门槛。 |
| 风格差异 | 双方可靠发送各至少 10 次／2 日，按 `min(100,K_A,K_B)` 做等量稀释；预期种类比至少 1.8、差至少 3、D2 比至少 1.5 同时成立才输出。限定可辨认素材，不推断未知身份或性格。 |

本轮没有修改七项算法阈值。短期、稀疏、未知素材较多时，确实可能没有采用、
重逢或风格候选；放宽这些门槛可能把缺失身份误当作缺席，或把单次共享称为习惯，
没有证据支持本轮普遍降低。已证实不合理的是共同习惯在算法之后又被二次提高门槛。

## 关联、精选和展示中的具体问题

完整算法候选没有被前三截断。故事按同一可靠素材、成员交集、相距至多七日、
合并锚点跨度至多 90 日且无已知缺口关联；跨年独立事件不合并。
全历史招牌／共同习惯只附到一个事件，重叠接力窗口关联成一场事件，保留原候选引用。
因此“其他六类没体现”可能来自原本不满足资格，也可能已经关联在一条故事里。

旧精选只按兴趣等级、归一强度、关联数量和稳定 ID 排序，截前三，没有不同素材间的
内容重复控制。大幅趋势可以达到第三级；短于 180 日的重逢、普通接力和共同使用通常
只有第一级。相似采用只要换素材就占另一名额；多个素材的上升／下降可以挤掉其他主题。
另外，共同习惯最低合格候选被赋零级，连空余名额都不能进入。

旧报告在关联故事内固定优先使用趋势标题，即使同一故事还含共同习惯，
视觉上仍可能表现为又一条趋势。报告本身没有第二次按数量或缺图删故事：
每条至多三张代表素材，可靠素材缺图保留占位；代表图选择不依赖恢复状态。
最多三条精选及其每条三张代表图，是有意的展示边界，不是七项算法的产出上限。

本轮在现有 owner 内修改：

1. 最强故事仍先选；之后优先加入尚未展示的合格主题，不设置七类固定栏目。
2. 素材身份不作为内容新颖性的充分理由。同一后用方的采用、同一方同方向的趋势、
   同一方的招牌／重逢、共同使用各保留代表；另一方、不同趋势方向及不同接力事件可补位。
   已被选中故事覆盖的模式不重复填满，没有新内容时允许少于三条。
3. 共同习惯按已有算法资格进入故事选择；没有提高名额或放松事实与身份条件。
4. `lead_finding` 让报告主发现跟随本次选择的新主题，全部关联事实仍保留为后续内容。
   该字段只在进程内，不扩张分享字段或原文导出权限。

`private-sticker-stories.v2` 只表示编辑精选策略修订，七项算法仍为
`private-stickers.v1.1-batch2`。候选、关联、基础统计、素材身份与媒体恢复算法没有变化。

## 正式算法的虚构前后对照

下表顺序为正式报告实际主发现顺序。前态使用起点提交的故事选择与报告投影；
后态使用修复源码；两态消费同一份正式算法候选。全部关联组的 `findings` 引用一致。

| 虚构场景 | 修复前 | 修复后 |
| --- | --- | --- |
| 独立采用挤占场景 | 365 天招牌；TA 晚 15 天首次可见使用；另一素材同样晚 15 天 | 365 天招牌；双方反复共用；一条晚 15 天使用。两条采用候选仍保留。 |
| 独立趋势挤占场景 | 三条主发现均为占比变化，含 100%→0% 和 0%→100% | 一条趋势；八轮接力；共同使用。共同使用故事关联的 0%→44% 仍保留，但不再抢占其主标题。六条趋势、一个接力、一个共同习惯候选均保留。 |
| daily | 0%→50% 趋势；晚 14 天使用 | 同一趋势；双方反复共用；晚 14 天使用。由两条变三条，新增来自原本合格候选。 |
| fighters | 12 轮接力；另两场 8 轮接力 | 相同。确有不同日期的独立互动，完整 15 场候选保留。 |
| unequal | 等量 40 次的风格差异 | 相同。不把基础榜已有的短期 Top 3 招牌补成故事。 |
| short | 一场 8 轮接力 | 相同。只有两天的聊天不会补出长期变化。 |
| old_friends | 本人 1456 天招牌；对方 1456 天招牌；217 天重逢 | 本人招牌；217 天重逢；对方招牌。先展示不同主题，两人的真实习惯均保留。 |
| rich_steady | 无故事 | 仍无故事。稳定轮换、无明显反差，不为了数量产出。 |
| new_fad | 一条 0%→87% 趋势，附带招牌背景 | 相同。五个扫描已关联为一条故事，没有把扫描次数变成故事数。 |

这些结果复现并修复了两类筛选缺陷，不能证明负责人的两份真实私聊必然新增多少故事。
另一种主题必须先满足事实资格，精选仍最多三条，后续真人验收关注内容差异及实际价值。

## 验证范围与留项

使用已验证的现有虚拟环境，显式导入目标 worktree 源码；没有安装或升级依赖。
现有 bootstrap 完整性回归在修复前直接失败，修复后通过。
两个新增回归位于既有测试文件，分别复现采用重复占位与趋势挤掉接力／共同习惯；
没有新增测试文件、公共辅助工具、参数矩阵，也没有删除安全或历史回归。
现有正式 QQ／微信适配器、分析、HTML／JSON 分享边界、媒体目标与占位回归继续通过。
QQ 实际 HTTP bridge 的认证、worker 代际、身份复核、下载租约、分块传输、
快照生命周期和隔离工作副本由既有虚构集成覆盖。
Windows 符号链接权限不足的用例跳过，不能算该环境已验证链接攻击的全部路径。

本轮没有启动真实 QQ／微信、登录、获取真实消息或媒体，没有变更正式安装。
未覆盖真实客户端冲突退出、端口占用、在线连接、快照采集、长报告性能、
真实动画及未知媒体分布；没有执行 Frozen／Setup 构建、安装、跨机器或发行验收。
当前 candidate 与本地提交供负责人审核，之后再由负责人进行授权的真人连接和报告体验验收。
